# تطبيق أَثَر | ATHAR — دليل بناء ملف APK الحقيقي لهواتف Android

مرحباً بك! تطبيق **أَثَر | ATHAR** مصمم ليمنحك تجربة إسلامية فاخرة باللونين الأسود والذهبي.
هذا المجلد يحتوي على الكود المصدري الكامل لمشروع **Flutter & Dart** القابل للبناء كملف APK حقيقي وتثبيته مباشرة على أي هاتف يعمل بنظام أندرويد.

---

## 🚀 طريقة بناء ملف الـ APK في 4 خطوات بسيطة:

### الخطوة 1: تثبيت متطلبات Flutter
تأكد من تثبيت Flutter SDK و Android Studio على حاسوبك:
```bash
flutter doctor
```

### الخطوة 2: الدخول لمجلد المشروع وتثبيت الحزم
```bash
cd flutter_athar
flutter pub get
```

### الخطوة 3: بناء ملف APK بصيغة Release
قم بتشغيل الأمر التالي:
```bash
flutter build apk --release
```

أو لبناء حزم منفصلة لكل معالج لتقليل حجم الـ APK إلى أدنى حد:
```bash
flutter build apk --split-per-abi
```

### الخطوة 4: موقع ملف الـ APK وتثبيته على الهاتف
بمجرد اكتمال البناء، ستجد ملف الـ APK داخل المسار التالي:
```
build/app/outputs/flutter-apk/app-release.apk
```
يمكنك نقل هذا الملف إلى هاتفك عبر كابل USB أو تطبيق WhatsApp/Telegram وتثبيته مباشرة بضغطة واحدة!

---

## 📱 التثبيت الفوري كـ WebAPK دون الحاجة لحاسوب:
إذا كنت ترغب في تشغيل التطبيق وتثبيته فوراً على هاتفك الذكي دون الحاجة للبناء اليدوي:
1. افتح رابط التطبيق في متصفح **Google Chrome** على هاتفك.
2. اضغط على قائمة الخيارات (⋮) أعلى يمين الشاشة.
3. اختر **«تثبيت التطبيق»** أو **«إضافة إلى الشاشة الرئيسية»**.
4. سيقوم نظام أندرويد تلقائياً بإنشاء أيقونة تطبيق أصلي في قائمة تطبيقاتك يعمل بكامل مميزاته ودون إنترنت!
